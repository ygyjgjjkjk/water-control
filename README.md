# Smart Water AI — Intelligent School Water Infrastructure

A fully local digital prototype of an AI/IoT water monitoring platform for schools. No physical hardware, no external APIs, no cloud services — every sensor reading, anomaly, and camera feed is generated by an in-browser simulation engine.

## Running locally

```bash
npm install
npm run dev
```

Open the printed `localhost` URL. `npm run build` produces a static production bundle.

## What's inside

- **Overview** — top-line KPIs, live consumption chart, AI infrastructure status.
- **Live Monitoring** — per-zone real-time flow with sparklines.
- **Digital Twin** — interactive 3-floor building model; click a room for its sensor data.
- **AI Detection** — statistical baseline/anomaly engine (`baseline + 2σ` threshold), classifying Hidden Leak / Open Tap / Toilet Leak / Pipe Burst / Unusual Consumption.
- **Smart Vision** — simulated sink camera with switchable scenarios and a 15-second water-waste timer.
- **IoT Network** — virtual ESP32 / Raspberry Pi device fleet with battery, signal, and telemetry.
- **Alerts** — filterable alert center with investigate/resolve actions.
- **Impact** — projected economic and environmental impact (clearly labeled as simulation/estimation).
- **Presentation Mode** (`/presentation`) — a minimal, big-KPI view for demos to stakeholders.
- **Demo Mode** — a scripted end-to-end scenario: normal → leak detected → alert → Digital Twin highlight → resolution.

## Architecture

```
src/
  components/   UI primitives, charts, layout chrome, vision scene
  pages/        one file per route
  data/         mock 7-day dataset + diurnal consumption model
  simulation/   zustand store driving the whole app (tick every 1s = 1 simulated minute)
  services/     the local "AI" — statistical anomaly detection, cost/loss estimation
  types/        shared TypeScript types
  hooks/        simulation clock
```

Everything reactive on screen reads from one Zustand store (`src/simulation/store.ts`), which is ticked once per second and re-derives zone flow, anomalies, alerts, vision state, and device telemetry from simple statistical models — no ML training, no network calls.
